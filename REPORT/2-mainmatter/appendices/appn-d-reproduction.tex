\chapter{Reproducing the Results}
\label{appn:reproduction}

All results in this thesis were produced with the code available at
\url{https://github.com/sakthe1010/MEIO\_DDP}.  The following commands
reproduce each experiment from scratch.
A Python 3.10+ virtual environment with pip install -r requirements.txt
is assumed.

%% -----------------------------------------------------------------------
\section*{Prerequisites}

\begin{verbatim}
# Clone repository and install dependencies
git clone https://github.com/sakthe1010/MEIO_DDP.git
cd MEIO_DDP
pip install -r requirements.txt
\end{verbatim}

%% -----------------------------------------------------------------------
\section*{Run the Test Suite}

\begin{verbatim}
python -m pytest tests/ -q
\end{verbatim}

%% -----------------------------------------------------------------------
\section*{Single Simulation Run (E0 baseline)}

\begin{verbatim}
python scripts/run_simulation.py --config config/1n3_5sku.json
\end{verbatim}

%% -----------------------------------------------------------------------
\section*{Full Experiment Suite (E0--E9)}

\begin{verbatim}
python scripts/run_experiments.py \
    --config config/1n3_5sku.json \
    --experiments E0 E1a E1b E2 E3 E3_per_sku E4 E5 E6 E7 E8 E9 \
    --trials 100 \
    --warmup 30
\end{verbatim}

Output is written to outputs/experiments\_\textlangle ts\textrangle /.

%% -----------------------------------------------------------------------
\section*{Run Specific Experiments}

\begin{verbatim}
# Core optimisation experiments only
python scripts/run_experiments.py \
    --config config/1n3_5sku.json \
    --experiments E0 E3 \
    --trials 100

# Pareto frontier
python scripts/run_experiments.py \
    --config config/1n3_5sku.json \
    --experiments E4 \
    --trials 100

# Extension experiments (disruption, policy comparison,
# forecast sensitivity, bullwhip-aware)
python scripts/run_experiments.py \
    --config config/1n3_5sku.json \
    --experiments E5 E6 E7 E8 \
    --trials 100

# Stochastic demand robustness (requires E3 params)
python scripts/run_experiments.py \
    --config config/1n3_5sku.json \
    --experiments E9 \
    --trials 100
\end{verbatim}

%% -----------------------------------------------------------------------
\section*{Generate Plots}

\begin{verbatim}
python scripts/plot_results.py \
    --expdir outputs/experiments_<timestamp>/
\end{verbatim}

Produces PNG plots in outputs/experiments\_\textlangle ts\textrangle /plots/:
cost\_breakdown.png, fill\_rate.png,
inventory\_ts.png, orders\_ts.png,
bullwhip.png, pareto\_frontier.png.

%% -----------------------------------------------------------------------
\section*{Multi-Seed Statistical Validation}

\begin{verbatim}
python scripts/multi_seed_validation.py \
    --config config/1n3_5sku.json \
    --params outputs/experiments_<timestamp>/E3/params.json \
    --seeds 5
\end{verbatim}

Reports cross-seed mean and standard deviation of cost and fill rate.
Under the canonical deterministic M5 configuration, cross-seed variance
is zero; confidence intervals become informative only when Poisson or
stochastic lead-time demand is used.

%% -----------------------------------------------------------------------
\section*{Build Config from CSV}

\begin{verbatim}
python inputs/scripts/build_config_from_csv.py
# Writes inputs/config/generated_from_csv.json

python scripts/run_simulation.py \
    --config inputs/config/generated_from_csv.json
\end{verbatim}

%% -----------------------------------------------------------------------
\section*{Exact Run Used in Thesis}

The results reported in Chapter~\ref{chap:results} were produced with
random seed 42, 100 Optuna trials, and 30-day warm-up on the
\texttt{config/1n3\_5sku.json} configuration.  The precise trial-level
parameters are saved in the \texttt{E*/params.json} files of each
experiment output directory and can be used to reproduce the exact
results.
